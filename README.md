# 대화 흐름판 (talk-flow 갈래)

대화 중에 녹음 버튼 한 번 → 실시간 받아 적기 → 「분석」 누르면 누가 한 말인지 추정하고,
각자 심리·의도(근거 발언 포함)와 지금 할 말 한 줄을 보여 주는 본인용 안드로이드 앱.

- 화면: `app/src/main/assets/index.html`
- 녹음·분석 연결: `app/src/main/java/com/myskynet2/talkflow/MainActivity.java`
- 이 갈래에 올리면 깃허브가 앱 파일(talkflow.apk)을 만들어 Releases 에 올림 (태그 talk-v1.0.N)
- main 갈래의 현장계산기와는 별개. 서로 영향 없음.
